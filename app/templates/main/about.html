About DevBlog

DevBlog is a full-featured blogging web application developed as an internship project using modern Flask practices.

Key Technologies

  • Flask — Micro-framework with Application Factory pattern Backend
  • Flask-SQLAlchemy — Object Relational Mapping (ORM) Database
  • Flask-Migrate — Database schema migrations via Alembic Migrations
  • Flask-Login — Session management & authentication Auth
  • Bootstrap 5 — Responsive styling & modern UI Frontend
